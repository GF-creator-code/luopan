# 「出海罗盘」（暂定名）作品方案 v0.9

第二届全国人工智能应用创新大赛 · 通用赛道 · 命题领域「出海」· 方向：**全球业务智能决策**
方案日期：2026-10-12（数据源当日实测全部通过）

## 0. 一句话定位

中小企业/品牌方输入"我有一个什么产品"，Agent 自动完成出海目标市场的筛选与优先级排序，产出一份带公开数据溯源的《出海目标市场决策报告》，并支持就报告结论多轮追问。

## 1. 与章程/命题的对齐（评委视角）

| 章程要求（原文） | 本作品如何满足 |
|---|---|
| "可验证智能体交互能力"（第一条） | Agent 工具调用轨迹全程可视化（规划→行动→观察）；报告全部数字带指标代码/年份/来源标注；同一输入一键复现（全量缓存） |
| "人工智能技术应用"（第十五条） | LLM 产品理解与 HS 编码映射、工具调用编排、报告叙事生成、多轮追问归因 |
| "问题解决能力"（第十五条） | 对准真实决策痛点：出海选市场靠拍脑袋或买二手报告；给出可复算的量化排序与依据 |
| "创新价值"（第十五条） | 把周级的行业研究压缩为分钟级可交互决策；数据全部可溯源可复算，非黑盒 |
| "可落地性"（第十五条） | 数据全部来自免费公开权威源（世界银行/联合国商品贸易库），无爬虫合规风险，SaaS 化路径清晰 |

通用赛道命题方向为"AI Agent 赋能行业创新"，出海为重点领域之一（第十六条）；本作品聚焦「出海」内容中的**全球业务智能决策**。

## 2. 目标用户与场景故事

- 用户：工厂型卖家 / 品牌出海负责人 / 外贸新人；需要快速形成市场进入备忘录的行业研究人员
- Demo 剧本：便携咖啡机厂商想出海，预算有限只能先打 1-2 个国家 → 输入产品与约束 → 约 3 分钟得到 Top5 市场排名与国别画像报告 → 追问"如果只看东南亚呢" → Agent 按约束即时重排并解释

## 3. 功能边界

### 做（校赛 MVP）

1. **产品理解**：自由文本 → 结构化产品档案（品类/价位段/关键属性）+ HS6 编码映射（LLM + 人工校对表兜底，界面可手改）
2. **候选市场池**：内置约 20 个主要消费国（美/德/日/英/法/韩/澳/加/荷/意/西/墨/印尼/泰/越/马/菲/印/沙特/阿联酋/巴西），可增删
3. **数据采集**：World Bank 宏观指标 + UN Comtrade 品类贸易额，全量本地缓存
4. **多准则评分排序**：六指标加权，权重滑条实时重算
5. **决策报告**：docx（导出 PDF），含排名表、Top5 国别画像（雷达+趋势图）、风险提示、数据溯源附录
6. **多轮追问**：约束式重排（"只看亚太"）、两国对比、指标解释

### 不做（边界外，防 scope 爆炸）

- 不做海外竞品/评论实时爬取（合规 + 时间风险）
- 不做营销文案生成（属"跨语言营销"方向，划清界限）
- 不做关税精确计算与法务合规意见（报告只做提示性风险标注）
- 不承诺进口商/渠道名录

## 4. Agent 架构

```
Streamlit UI（输入表单 + 聊天面板 + 轨迹展示 + 权重滑条 + 报告下载）
  └─ Orchestrator（LLM 驱动 plan → act → observe 循环）
       ├─ tool: parse_product        LLM 产品解析
       ├─ tool: map_hs_code          LLM 映射 + 校对表兜底
       ├─ tool: fetch_worldbank      indicator/countries/years
       ├─ tool: fetch_comtrade       hs6/reporters/years
       ├─ tool: score_markets        纯代码，可复算
       ├─ tool: build_report         纯代码 + 模板（数字零幻觉）
       └─ tool: answer_followup      LLM，引用数字台账
数据层：requests + 本地 JSON 缓存（防限流、保复现、断网可演示）
LLM：OpenAI-compatible endpoint，环境变量注入（LLM_BASE_URL / LLM_API_KEY / LLM_MODEL）
```

三条关键工程决策：

1. **评分与报告生成走确定性代码，LLM 只做理解/编排/叙事** → 报告数字 100% 可复算，直接回应章程"可验证"。
2. **Agent 轨迹（thought/action/observation）前端全程展示** → 评委看得见"智能体在干活"，而非套壳聊天。
3. **全量数据缓存落盘** → 演示现场断网也能跑；录屏兜底。

## 5. 数据源清单（2026-10-12 实测）

| 数据源 | 用途 | 接口 | 密钥/限额 | 实测结果 |
|---|---|---|---|---|
| World Bank API v2 | 人均GDP、人口、互联网渗透率、物流绩效 LPI 等 | `api.worldbank.org/v2/country/{list}/indicator/{code}` | 免密钥 | ✅ 单国+分号多国批量 OK（数据 2026-10-08 更新） |
| UN Comtrade Public Preview | HS6 进口额（规模+3年增速）、中国出口占比 | `comtradeapi.un.org/public/v1/preview/C/A/HS` | 免密钥、有限流 | ✅ 0.22s 返回 61 条（日本 2023 HS8419 进口） |

核心指标初选：

- World Bank：`NY.GDP.PCAP.CD`（人均GDP）、`SP.POP.TOTL`（人口）、`IT.NET.USER.ZS`（互联网渗透）、`LP.LPI.OVRL.XQ`（物流绩效）
- Comtrade：该 HS6 自全球进口额（最近年）、进口额 3 年 CAGR、中国出口占其进口比
- 待补（P2，时间允许再加）：WDI 关税均值（风险维度）、CEPII 距离变量（可选）

复现脚本：`spike/verify_datasources.sh`（首测日志 `notes/datasource_check_2026-10-12.log`）。

## 6. 评分模型 v0.9

各指标 min-max 归一化到 0-10，加权求和；权重用户可调（滑条），重排即时生效。

| 维度 | 指标 | 默认权重 | 说明 |
|---|---|---|---|
| 市场规模 | 该 HS6 进口额（美元） | 25% | Comtrade 最近年 |
| 市场增长 | 进口额 3 年 CAGR | 20% | |
| 购买力 | 人均 GDP | 15% | |
| 供给接受度 | 中国对该国出口占其该 HS6 进口比 | 20% | 高→中国货接受度高；竞争提示放报告文字层 |
| 数字就绪 | 互联网渗透率 | 10% | 线上渠道基础 |
| 物流就绪 | LPI 综合分 | 10% | |
