# 部署与体验指南

## 一、本机体验（最快，30 秒）

双击 `run.cmd`，或命令行执行：

```bash
python -m streamlit run app.py --server.address localhost --browser.gatherUsageStats false
```

浏览器自动打开 http://localhost:8501 —— 输入产品描述 → 开始分析 → 看轨迹/排名/点评 → 底部追问框随便问。

注意：`.env` 里是 OneTop 按 Key，本机体验正常计费（每次分析约 3-5 次 LLM 调用）。

## 二、免费托管：Streamlit Community Cloud（主推）

前提：GitHub 账号（本机暂无 gh CLI/token，push 由你执行或提供 token）。

1. 在 GitHub 建一个仓库（如 `luopan`，Public）
2. 本地已备好 git 仓库（首次提交已完成，`.env`/`data/cache` 均在 .gitignore 中不会上传）：

   ```bash
   cd C:\Users\25345\.zcode\workspace\default\ai-race-2026
   git remote add origin https://github.com/<你的用户名>/luopan.git
   git push -u origin main   # 如默认分支是 master 则相应调整
   ```

3. 打开 https://share.streamlit.io → 用 GitHub 登录 → Create app → 选仓库 → 主文件 `app.py` → Deploy
4. **部署后必做**：App 菜单 → Settings → Secrets，填入：

   ```toml
   LLM_BASE_URL = "https://www.onetopai.com/v1"
   LLM_API_KEY = "sk-****"
   LLM_MODEL = "deepseek-v4.1-flash"
   ACCESS_CODE = "你给评审的访问码"
   ```

   （Streamlit 会把 Secrets 自动注入环境变量，代码零改动读取。）

5. **设 ACCESS_CODE 的原因**：公网链接任何人可访问，LLM 每次分析都烧 OneTop 余额。访问码既保护额度，又正好满足大赛"提供评审账号密码"的要求——比赛时把访问码连同链接交给组委会即可。

国内访问 `*.streamlit.app` 时好时坏（多数地区可直连）。部署后先用手机流量（不走 WiFi）实测一次；如果打不开，换备选方案。

## 三、免费托管备选：内网穿透（不用 GitHub）

cpolar / natapp 免费版：本机 `streamlit run app.py` + 隧道 → 得到公网 URL。
优点：五分钟搞定、国内访问稳；缺点：免费版 URL 每次重启会变、电脑要一直开机。
适合给朋友/导师演示，**不适合**作为提交给评审的正式链接（稳定性不够）。

## 四、正式提交前的部署要求（提醒）

- 评审期间链接必须持续可访问、账号密码真实有效（报名须知硬检项）→ 免费额度到期、机器关机都会翻车
- 建议：正式版迁到付费轻量服务器（¥100/月级别）或至少付费版隧道，D6-D7 再决定
- 匿名红线同样适用于部署的 UI（当前 UI 无任何身份信息 ✓）

## 五、云端行为说明

- 云端没有本地缓存目录的持久性：8 个预设品类数据已随仓库 fixtures 分发（876KB），开箱即用
- 新品类（如空气炸锅）首次分析会**按需实时抓取** 21 次调用（约 2 分钟，进度条可见），之后走缓存
- Comtrade 匿名额度未知，云端公网多人使用可能触发限流 → 限流时该国数据缺失会标"待补"，评分不崩
